Privacy

Privacy policy

Last updated October 20, 2026

Folio has no account, no analytics and no telemetry. It sends nothing to Basalt.

Who is responsible

Folio is published by Basalt (hellobasalt.dev), an independent software studio. For any privacy question or request, write to support@hellobasalt.dev.

The Folio app

  • What it runs. Folio starts a copy of opencode (the "press") on your computer, on a local address only it knows, with a password made for each launch. The window talks to it over that local connection.
  • What leaves your computer. opencode sends your messages, and the parts of your files it reads, to the AI model provider you choose (by default the free OpenCode Zen models run by the opencode team; or a provider whose key you paste). That is how any coding agent works. Those providers' own privacy terms apply. Basalt never sees this traffic.
  • What it stores. opencode keeps your sessions, any provider keys you paste, and its cache in Folio's app data folder on your computer (on macOS, ~/Library/Application Support/app.folio.desktop/press). Folio keeps its reading settings and which plates you accepted or folded in the window's local storage. None of it is uploaded.
  • Your files. Folio reads and writes files only inside the folder you open as a book, and only to show or undo the changes opencode makes.
  • Installing opencode. If you run Folio without its bundled copy and choose Install opencode, it runs the official installer from opencode.ai.

This website

This site is a set of static pages served by Cloudflare. It has no accounts, forms, advertising or tracking scripts, and its fonts are served from this site.

  • Visit statistics. We use Cloudflare Web Analytics to count visits. It shows us aggregate numbers only (page views, country, browser type, referring site and load speed), sets no cookies and creates no identifier that recognises you.
  • Security cookie. If Cloudflare's security system sees unusual traffic, it may show a short check and set a security cookie called cf_clearance. It is used only to protect the site, never for ads or analytics.
  • Downloads. The app files are hosted on GitHub. GitHub may log technical details such as IP addresses to run and secure its service; see the GitHub General Privacy Statement.

Changes and questions

If this policy changes, the new version is published here and its history is in the repository. For questions or requests about your data, email support@hellobasalt.dev.
